# Contributing to Braid

## Licence and sign-off

- Contributions are licensed under AGPL-3.0-or-later (code) and CC BY-SA 4.0 (spec text), the same as the project.
- Sign off every commit with `git commit -s`. This certifies the [Developer Certificate of Origin](https://developercertificate.org/).
- New source files start with the two SPDX lines used elsewhere in the tree.

## Style

- Plain ASCII punctuation in code and docs: use `-`, `...` and straight quotes. No em dashes, curly quotes or other non-ASCII characters. Check with `grep -rnP '[^\x00-\x7F]' <files>`.

## Before opening a PR

1. Host tests, all must pass:
   ```
   cmake -S firmware/host -B firmware/host/build
   cmake --build firmware/host/build
   ctest --test-dir firmware/host/build
   ```
2. Both device builds, with zero warnings (from `firmware/`):
   ```
   pio run -e esp32_dev
   pio run -e esp32s3_dev
   ```

## Spec changes

- Change `PROTOCOL.md` and record the decision in `SPEC-NOTES.md` in the same PR.
- Earlier drafts (`PROTOCOL.v0.*.md`) are frozen. Do not edit them.

## Test vectors

- `firmware/test/host/vectors_generated.h` and the Appendix A body in `PROTOCOL.md` are generated by `tools/vectors.py`. Never hand-edit them. Change the script and regenerate:
  ```
  python3 tools/vectors.py
  python3 tools/vectors.py --emit-c firmware/test/host/vectors_generated.h
  ```

## Security issues

Report vulnerabilities privately by opening a GitHub security advisory on this repository. Do not file public issues for them.
